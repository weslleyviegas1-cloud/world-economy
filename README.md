# World Economy

ETAPA 1 — WORLD ECONOMY



Identidade visual, interface completa e estrutura principal



Quero que você desenvolva a identidade visual e a estrutura inicial do meu aplicativo chamado WORLD ECONOMY — SIMULAÇÃO GLOBAL DE PAÍSES.



Esta é a primeira etapa de um projeto dividido em 15 etapas. Desenvolva esta etapa com muito cuidado, pois ela será a base visual e estrutural de todo o aplicativo.



1. REFERÊNCIAS VISUAIS OBRIGATÓRIAS



Estou enviando imagens de referência que foram criadas especificamente para este projeto.



Sua obrigação é reproduzir essas referências com ALTÍSSIMA FIDELIDADE.



Não quero um aplicativo genérico inspirado nas imagens. Quero que você utilize as imagens como referência direta para reconstruir a identidade visual, a disposição dos elementos, os painéis, os menus, os cartões, os ícones e a organização das informações.



As imagens apresentam três experiências principais:



1. Painel administrativo geral (Super Admin).

2. Painel individual do cidadão.

3. Painel administrativo do presidente de um país.



Utilize todas as imagens enviadas. Cada uma complementa as outras.



Não descarte elementos visuais importantes das referências.



2. IDENTIDADE VISUAL E LOGOTIPO



O nome oficial será:



WORLD ECONOMY



Subtítulo:



SIMULAÇÃO GLOBAL DE PAÍSES.



Quero preservar a identidade visual da logo que aparece nas imagens enviadas.



Utilize o símbolo do globo terrestre com a coroa e os elementos dourados de louros como referência para reconstruir e recortar a logo original das imagens.



Não invente outra logo, não substitua o símbolo por um ícone genérico e não altere a identidade visual.



Se necessário, faça o tratamento da imagem para obter uma versão limpa, transparente e de alta qualidade.



Paleta de cores



- Preto profundo.

- Azul-marinho.

- Azul luminoso para destaques.

- Branco para textos principais.

- Cinza para informações secundárias.

- Dourado para elementos especiais, conquistas e destaques.



A aparência deverá ser sofisticada, tecnológica, moderna e profissional.



3. INTERFACE RESPONSIVA



Desenvolva duas versões perfeitamente adaptadas:



Mobile:



- Interface otimizada para celulares Android e iPhone.

- Menus inferiores ou laterais adaptados.

- Cartões organizados verticalmente.

- Botões fáceis de utilizar.

- Informações sem cortes.

- Navegação confortável em telas pequenas.



Desktop:



- Painéis completos para computadores.

- Menus laterais.

- Cabeçalhos organizados.

- Cartões informativos.

- Gráficos e tabelas.

- Aproveitamento adequado do espaço horizontal.



Não quero simplesmente uma versão de computador espremida no celular. Cada dispositivo deverá ter sua própria adaptação visual.



4. ANIMAÇÕES E TRANSIÇÕES



Quero uma experiência visual extremamente refinada.



Implemente:



- Transições suaves entre páginas.

- Menus que abrem e fecham com animações.

- Cartões com entrada suave.

- Botões com efeitos ao pressionar.

- Animações de carregamento elegantes.

- Gráficos com animações de entrada.

- Indicadores luminosos.

- Efeitos discretos de profundidade.

- Transições entre painéis.

- Animações de modais e janelas.



As animações devem ser modernas, fluidas e profissionais, sem exageros que prejudiquem a usabilidade.



Utilize tecnologias adequadas para garantir bom desempenho em celulares.



5. TELA INICIAL E CADASTRO



Antes de entrar no painel, o usuário deverá visualizar uma tela inicial bonita, com a identidade visual do WORLD ECONOMY.



Criar:



- Tela de boas-vindas.

- Criar conta.

- Entrar na conta.

- Recuperação de senha.

- Login com Google.

- Cadastro por e-mail.

- Campo de nickname do Minecraft.

- Identificação exclusiva do jogador.



Após o cadastro, o usuário deverá escolher entre:



OPÇÃO A — PRESIDENTE



O jogador deseja solicitar a presidência de um país.



Ele poderá visualizar os países disponíveis, suas bandeiras e as vagas disponíveis.



A solicitação deverá ficar pendente até que o Super Admin aprove.



OPÇÃO B — CIDADÃO



O jogador deseja participar de um país já existente.



Ele deverá escolher sua nacionalidade entre os países disponíveis para cidadãos.



Importante: se não houver mais países disponíveis para receber novos presidentes, a opção de solicitar presidência deverá desaparecer automaticamente.



O usuário comum não poderá se tornar presidente simplesmente selecionando essa opção.



6. PAINEL DO SUPER ADMIN



Este será o painel mais completo do aplicativo.



O Super Admin terá uma visão global do WORLD ECONOMY.



Desenvolva uma interface inspirada diretamente no painel administrativo das imagens.



Quero visualizar:



- Total de países cadastrados.

- Total de jogadores.

- Total de presidentes.

- Total de bancos.

- Total de empresas.

- Indicadores da economia global.

- Notícias internacionais.

- Ranking econômico.

- Ranking militar.

- Ranking das moedas.

- Atividade geral da plataforma.

- Solicitações de cadastro.

- Solicitações de presidência.

- Gerenciamento de países.

- Gerenciamento de usuários.

- Configurações gerais.

- Logs e registros administrativos.



Criar também uma seção de gerenciamento de países com:



- Nome do país.

- Bandeira.

- Identificação.

- Coordenadas oficiais.

- Coordenadas de nascimento.

- Disponibilidade para novos presidentes.

- Disponibilidade para novos cidadãos.

- Status do país.



O Super Admin poderá cadastrar, editar, disponibilizar ou suspender países.



Também deverá existir uma área para definir as coordenadas globais do servidor e as coordenadas oficiais de cada país.



7. PAINEL DO CIDADÃO



O cidadão deverá visualizar somente suas próprias informações e os serviços aos quais tem autorização.



O painel deverá apresentar:



- Foto ou avatar do jogador.

- Nickname.

- ID exclusivo.

- Nacionalidade.

- Bandeira do país.

- Informações do país.

- Banco em que possui conta.

- Informações bancárias.

- Emprego atual.

- Cargo profissional.

- Empresas em que trabalha.

- Documentos.

- Passaporte.

- Veículos registrados.

- Carteira de motorista.

- Possibilidade de viajar.

- Notícias nacionais.

- Notícias internacionais.



Criar também um cartão especial chamado:



TELETRANSPORTE PARA SEU PAÍS



Esse cartão deverá apresentar as coordenadas oficiais fornecidas pelo administrador.



Adicionar botão para copiar as coordenadas e apresentar o formato de comando:



"/tp X Y Z"



O jogador deverá conseguir copiar o comando para utilizar manualmente dentro do Minecraft.



Não implemente integração com API do Minecraft.



8. PAINEL DO PRESIDENTE



Cada presidente terá um painel exclusivo do próprio país.



O painel deverá apresentar:



- Bandeira nacional.

- Nome do país.

- População.

- PIB nacional.

- Crescimento econômico.

- Inflação.

- Posição no ranking global.

- Notícias nacionais.

- Indicadores econômicos.

- Informações governamentais.

- Ministérios.

- Banco Central.

- Forças Armadas.

- Empresas nacionais.

- Infraestrutura.

- Relatórios.



Criar menus próprios para administração nacional.



O presidente não poderá visualizar ou modificar os dados administrativos de outros países sem autorização.



9. ESTRUTURA DE NAVEGAÇÃO



Organize a navegação de acordo com o tipo de usuário.



Super Admin, Presidente e Cidadão deverão possuir menus próprios.



Cada opção deverá abrir sua respectiva página ou tela.



Não coloque todos os menus de todos os perfis na mesma interface.



Prepare os espaços e a estrutura visual para as próximas etapas, sem implementar prematuramente os sistemas financeiros, militares, empresariais e governamentais completos.



10. ARQUITETURA E ORGANIZAÇÃO



Prepare uma estrutura de projeto organizada, escalável e modular.



Utilize componentes reutilizáveis.



Mantenha separados:



- Componentes visuais.

- Layouts.

- Páginas.

- Navegação.

- Autenticação.

- Perfis e permissões.

- Estrutura de dados.

- Configurações.



Prepare a arquitetura para receber banco de dados e autenticação reais nas próximas etapas.



Não crie dados financeiros reais.



Não invente integração com Minecraft.



Não utilize informações fictícias como se fossem dados reais.



Caso utilize informações demonstrativas para visualizar os painéis, identifique-as como demonstração.



11. REGRAS IMPORTANTES



1. Não descaracterize as imagens de referência.

2. Não substitua a logo original por outra.

3. Não mude a paleta de cores.

4. Não transforme o projeto em um dashboard genérico.

5. Não elimine nenhum dos três painéis.

6. Não misture as permissões dos usuários.

7. Não implemente funcionalidades financeiras incompletas fingindo que estão funcionando.

8. Não crie integração com API do Minecraft.

9. Não apague componentes ou estruturas existentes sem necessidade.

10. Mantenha a compatibilidade com as próximas 14 etapas.



12. TESTES E FINALIZAÇÃO



Antes de considerar esta etapa concluída:



- Teste a interface mobile.

- Teste a interface desktop.

- Verifique todos os menus.

- Verifique a navegação entre telas.

- Teste as animações.

- Verifique se não existem elementos cortados.

- Verifique a identidade visual.

- Verifique se a logo está corretamente aplicada.

- Verifique os três tipos de painel.

- Verifique se as permissões visuais estão separadas.



Quero uma experiência premium, com aparência de uma plataforma internacional de gerenciamento econômico e administrativo.



INSTRUÇÃO FINAL



Não simplifique o projeto.



Não faça uma versão básica apenas para entregar rapidamente.



Quero que você construa uma base visual profissional, muito bonita, extremamente organizada e com ALTÍSSIMA FIDELIDADE às imagens que estou fornecendo.



O resultado deverá parecer um aplicativo comercial de grande porte, pronto para receber as funcionalidades das próximas etapas.



WORLD ECONOMY — SEU PAÍS. SUA ECONOMIA. SEU FUTURO.



Ao concluir, apresente um resumo do que foi construído, quais telas estão funcionando, quais estruturas foram preparadas e o que ficou reservado para as próximas etapas.



Não avance para a Etapa 2 sem minha autorização.
